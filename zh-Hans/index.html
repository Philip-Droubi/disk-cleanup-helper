清理什么，以及从不触碰什么

每个项目都归入一个分组，告诉你需要多小心；在你勾选之前，它还会说明你会保留什么、失去什么。

  1. 安全

    可安全清理

    缓存和临时文件。程序会自行重建它们。

    例如： 浏览器和应用缓存（保留你的密码、书签、历史记录和登录状态）、临时文件、错误报告。

  2. 管理员

    旧安装程序文件和 Windows 清理

    需要管理员权限。选择前请先阅读每一项。

    例如： 已安装程序的旧更新文件（每个程序保留最新的 3 个）、Windows 更新下载内容、Microsoft 自己的 Windows 组件清理。

  3. 由你决定

    由你决定

    你会失去一些小东西。选择前请先阅读每一项。

    例如： 旧项目历史记录、已下载的歌曲、视频预览、崩溃转储文件、回收站中的内容。

  4. 设置

    Windows 设置

    可以释放空间或保持空间充足的开关。

    例如： 休眠、保留的存储、CompactOS 和存储感知。

  5. 仅供参考

    自行处理

    本工具只显示并打开这些项目，从不删除它们。

    例如： 以前的 Windows 安装、最大的程序、系统还原、Docker、WSL、你的“下载”文件夹。

“清理”选项卡从不触碰：你的文档、照片、音乐、视频、桌面和下载内容。

关于磁盘的一切

一个小程序，七个选项卡。

  • 清理

    安全清理浏览器和应用缓存、临时文件、旧的更新文件、Windows 残留文件等。

  • 分析磁盘

    显示任意驱动器上最大的文件夹和文件，帮你找出是什么占用了空间。

  • 磁盘健康

    显示每个磁盘是否健康、每个驱动器有多满，以及实时温度和历史图表。

  • SMART 详细信息

    每个磁盘完整的自我监测数据。

  • 磁盘性能

    实时磁盘活动，以及可供日后比较的速度测试。

  • 设备详细信息

    Windows、处理器、内存、显卡、屏幕、存储、电池、网络和声音。

  • 提示和常见问题

    让磁盘不被填满的简单习惯，以及常见问题的解答。

安全的设计，默认保护隐私

  • 在你选择并确认之前，不会删除任何内容。
  • 清理项目只处理缓存、临时文件和旧的更新文件。你的文档、照片、音乐、视频、桌面和下载内容永远不会被自动清理。
  • 清理浏览器和应用缓存时，会保留你的密码、书签、历史记录和登录状态。
  • 在清理浏览器或应用的缓存之前，它会请你先关闭该浏览器或应用。
  • 在计算大小、扫描或清理之前，如果电脑内存不足，它会提醒你。
  • 在“分析磁盘”选项卡中，Windows 和程序文件受到保护。
  • 它从不跟随文件夹链接进入其他文件夹。

隐私

它不会发送任何有关你电脑的信息。它只会询问 GitHub 是否有新版本，你可以在“关于”选项卡中关闭此功能。清理记录仅保存在这台电脑上。

常见问题

清理本应用建议的项目安全吗？

“可安全清理”组中的项目是程序会自行重建的缓存和临时文件。“由你决定”中的项目会删除一些小东西，所以请先阅读说明。标记为“仅供参考”的项目，本应用永远不会删除；它只显示这些项目并打开其位置。

清理浏览器缓存会让我退出网站登录吗？

不会。缓存清理会保留 Cookie、已保存的密码、书签和历史记录。极少数情况下，某个网站可能会要求你重新登录，浏览器会自动填入已保存的密码。

本应用会把我的数据发送到任何地方吗？

不会。它不会发送任何有关你电脑的信息。它唯一的联网操作是询问 GitHub 是否有新版本，每天最多一次。你可以在“关于”选项卡中关闭此功能。

更新是如何进行的？

有新版本发布时，应用会在后台下载并检查它：其 SHA256 和版本号必须与发布版本一致。随后会出现一个提示栏，提供“立即重新启动”。如果你选择“稍后”，更新会在你关闭应用时安装。你可以在“关于”选项卡中关闭自动检查；那里的“检查更新”按钮仍然可用。

为什么本应用需要管理员权限？

清理 Windows 自身的临时文件和更新文件，以及读取磁盘的健康数据，都需要管理员权限。如果你单击“否”，本应用仍然可以使用，需要管理员权限的项目会显示为灰色。

健康百分比是什么意思？

它是根据磁盘自身的自我监测数据（SMART，或 NVMe SSD 的健康日志）得出的估计值。100% 表示没有发现问题或磨损。它经过调整，结果接近 Hard Disk Sentinel 等工具，但每个工具都使用自己的公式，所以数字可能略有不同。

如何卸载？

“设置 > 应用 > Disk Cleanup Helper > 卸载”，或者使用“关于”选项卡中的“卸载”按钮。如果你从未安装过它，直接删除程序文件即可。
