Disk Cleanup Helper
===================
نوٹ پیڈ میں اس فائل کو دائیں سے بائیں پڑھنے کے لیے: Ctrl کے ساتھ دائیں Shift کی دبائیں۔

Windows 10 اور Windows 11 کے لیے ایک مفت اور اوپن سورس مددگار۔
یہ دکھاتا ہے کہ آپ کی ڈسکیں کس چیز سے بھری ہیں اور محفوظ طریقے سے جگہ خالی کرتا ہے۔
یہ ایک چھوٹی سی پروگرام فائل ہے۔ یہ آپ کے PC کے بارے میں کچھ نہیں بھیجتا؛ یہ صرف GitHub سے پوچھتا ہے کہ کیا کوئی نیا ورژن موجود ہے۔


یہ کیا کرتا ہے
-------------
صفائی              براؤزر اور ایپ کیشے، عارضی فائلوں، پرانی اپ ڈیٹ فائلوں، Windows کی بچی ہوئی فائلوں
                   اور مزید چیزوں کی محفوظ صفائی۔ ہر آئٹم بتاتا ہے کہ آپ کیا رکھتے ہیں اور کیا کھوتے ہیں۔
ڈسک کا تجزیہ        کسی بھی ڈرائیو پر سب سے بڑے فولڈرز (اندر دیکھنے کے لیے ڈبل کلک کریں) اور سب سے بڑی فائلیں
                   دکھاتا ہے، تاکہ آپ جان سکیں کہ آپ کی جگہ کس چیز نے گھیری ہے۔
ڈسک کی صحت         دکھاتا ہے کہ ہر ڈسک اور ڈرائیو صحت مند ہے یا نہیں اور کتنی بھری ہوئی ہے، براہ راست
                   درجہ حرارت اور سرگزشت کے چارٹس کے ساتھ، اور Windows کا اپنا خرابی اسکین شروع کرتا ہے۔
SMART تفصیلات       ہر ڈسک کا مکمل خود نگرانی کا ڈیٹا۔
ڈسک کی کارکردگی     ڈسک کی براہ راست سرگرمی اور رفتار ٹیسٹ۔
ڈیوائس کی تفصیلات    Windows، پروسیسر، میموری، گرافکس، اسکرینیں، اسٹوریج، بیٹری، نیٹ ورک
                   اور آواز، Windows کے DirectX تشخیصی ٹول کی طرح۔ اسے کاپی کریں یا ٹیکسٹ فائل کے طور پر محفوظ کریں۔
تجاویز اور سوالات    آسان عادتیں جو آپ کی ڈسک کو بھرنے سے بچاتی ہیں، اور عام سوالات کے جوابات۔
تعارف               اسے اسٹارٹ مینیو کے اندراج اور ڈیسک ٹاپ شارٹ کٹ کے ساتھ اپنے PC پر انسٹال کریں، یا ان انسٹال کریں۔
                   اپ ڈیٹس چیک کریں۔


کیسے شروع کریں
--------------
1. DiskCleanupHelper.exe پر ڈبل کلک کریں۔
2. Windows پوچھتا ہے "کیا آپ اس ایپ کو اپنے آلہ میں تبدیلیاں کرنے کی اجازت دینا چاہتے ہیں؟"۔ "ہاں" پر کلک کریں۔
   اگر آپ "نہیں" پر کلک کریں تو یہ پھر بھی کھل جاتا ہے، لیکن جن آئٹمز کو ایڈمن حقوق درکار ہیں وہ گرے ہوتے ہیں۔
3. اگر Windows پیغام "Windows نے آپ کے PC کا تحفظ کیا" دکھائے تو "مزید معلومات" پر، پھر "بہرحال چلائیں" پر کلک کریں۔
   یہ پیغام ان نئے پروگراموں کے لیے آ سکتا ہے جنہیں Microsoft ابھی نہیں جانتا۔
4. زبان: اوپر کونے میں زبان کے بٹن (گلوب) پر کلک کریں اور کوئی زبان منتخب کریں۔ ونڈو فوراً اس زبان میں بدل
   جاتی ہے اور آپ کا انتخاب یاد رکھتی ہے۔
5. ہلکا یا گہرا: اوپر کونے میں "گہرا موڈ" / "ہلکا موڈ" بٹن پر کلک کریں۔ ایپ آپ کا انتخاب یاد رکھتی ہے۔
6. اسے رکھنے کے لیے: "تعارف" ٹیب کھولیں اور "اس PC پر انسٹال کریں" پر کلک کریں۔
   پھر یہ اسٹارٹ مینیو میں، ڈیسک ٹاپ پر اور ترتیبات > ایپس میں نظر آتا ہے۔
   انسٹال کرنے کے لیے ایڈمن حقوق درکار نہیں۔


استعمال کیسے کریں
-----------------
"صفائی" ٹیب:
1. جن پروگراموں کی ضرورت نہیں انہیں بند کریں، خاص طور پر براؤزرز، چیٹ ایپس، کوڈ ایڈیٹرز اور گیمز۔
2. ایپ کھلتے ہی سائز خود بخود ناپے جاتے ہیں۔ اس میں ایک دو منٹ لگتے ہیں۔ روکنے کے لیے "روکیں" پر کلک کریں،
   یا دوبارہ ناپنے کے لیے "سائز ناپیں" پر کلک کریں۔
3. ہر گروپ اپنا کل سائز دکھاتا ہے۔ کسی گروپ کو سمیٹنے یا دوبارہ کھولنے کے لیے اس کے عنوان پر کلک کریں؛
   ایپ یاد رکھتی ہے کہ آپ نے کون سے گروپس سمیٹے ہیں۔
4. کسی بھی آئٹم پر کلک کر کے پڑھیں کہ وہ کیا ہے، کہاں ہے، اور آپ کیا رکھتے یا کھوتے ہیں۔
5. جو آئٹم صاف کرنا چاہتے ہیں اس کے خانے پر نشان لگائیں، یا "سب محفوظ منتخب کریں" پر کلک کریں۔
   ہر گروپ کا عنوان دکھاتا ہے کہ اس کے کتنے آئٹمز منتخب ہیں۔
6. "منتخب کردہ صاف کریں" پر کلک کریں۔ یہ پوری فہرست دکھاتا ہے اور کچھ بھی حذف کرنے سے پہلے پوچھتا ہے۔

"ڈسک کا تجزیہ" ٹیب:
1. کوئی ڈرائیو (یا "صرف میرا یوزر فولڈر") منتخب کریں اور "اسکین کریں" پر کلک کریں۔ پوری ڈرائیو میں چند منٹ لگ سکتے ہیں۔
2. ایک طرف: سب سے بڑے فولڈرز۔ اندر دیکھنے کے لیے فولڈر پر ڈبل کلک کریں، واپس جانے کے لیے "اوپر" پر کلک کریں۔
3. دوسری طرف: سب سے بڑی فائلیں۔ فائلیں منتخب کریں اور "ری سائیکل بن میں منتقل کریں" یا "مستقل طور پر حذف کریں" چنیں۔
   Windows اور پروگرام فائلیں محفوظ ہیں اور یہاں حذف نہیں کی جا سکتیں۔

"ڈسک کی صحت" ٹیب:
- ہر ڈسک دکھاتا ہے (ایڈمن حقوق کے ساتھ شروع کرنے پر درجہ حرارت، گھساؤ اور خرابیوں کی تعداد کے ساتھ)
  اور یہ کہ ہر ڈرائیو کتنی بھری ہوئی ہے۔
- جب تک ٹیب کھلا ہے، درجہ حرارت ہر چند سیکنڈ بعد خود بخود اپ ڈیٹ ہوتا ہے۔
- درست قدر اور اس کے محفوظ ہونے کا وقت دیکھنے کے لیے سرگزشت کے کسی چارٹ پر ماؤس رکھیں۔
- "خرابیوں کے لیے اسکین کریں" Windows ڈرائیو پر Windows کا اپنا صرف پڑھنے والا چیک چلاتا ہے۔
- "ڈرائیوز بہتر بنائیں" Windows کا اپنا ڈرائیو آپٹیمائزر کھولتا ہے۔

"ڈسک کی کارکردگی" ٹیب:
- دکھاتا ہے کہ منتخب ڈسک اس وقت کتنی مصروف ہے، پچھلے دو منٹ کے چارٹس کے ساتھ۔
  درست قدریں دیکھنے کے لیے کسی چارٹ پر ماؤس رکھیں۔
- "رفتار ٹیسٹ چلائیں" ناپتا ہے کہ ڈسک حقیقت میں کتنی تیزی سے لکھ اور پڑھ سکتی ہے۔ نتیجہ محفوظ ہو جاتا ہے،
  تاکہ آپ بعد میں موازنہ کر سکیں۔


صفائی کے گروپس کا مطلب
---------------------
محفوظ           کیشے اور عارضی فائلیں۔ پروگرام انہیں خود دوبارہ بنا لیتے ہیں۔
                براؤزر اور ایپ کیشے کی صفائی آپ کے پاس ورڈز، بک مارکس، سرگزشت اور لاگ انز برقرار رکھتی ہے۔
ایڈمن           انسٹال شدہ پروگراموں کی پرانی اپ ڈیٹ فائلیں (ہر ایک کی تازہ ترین 3 رکھتا ہے)،
                اور Microsoft کی اپنی Windows اجزاء کی صفائی۔
آپ کا فیصلہ      آپ کوئی چھوٹی چیز کھوتے ہیں: پرانی پروجیکٹ سرگزشت، ڈاؤن لوڈ کیے گئے گانے،
                ویڈیو پری ویوز، کریش ڈمپ فائلیں، یا جو کچھ ری سائیکل بن میں ہے۔
ترتیب           Windows کے سوئچ جو جگہ خالی کرتے ہیں: ہائبرنیشن، مخصوص اسٹوریج، CompactOS،
                اور اسٹوریج سینس۔
صرف معلومات     بڑی چیزیں جنہیں ٹول صرف دکھاتا اور کھولتا ہے، کبھی حذف نہیں کرتا: پچھلی Windows
                انسٹالیشن، سب سے بڑے پروگرام، سسٹم ریسٹور، Docker، WSL، ڈاؤن لوڈز۔

صرف وہ آئٹمز دکھائے جاتے ہیں جو آپ کے PC پر موجود ہیں۔


حفاظت
-----
- جب تک آپ منتخب کر کے تصدیق نہ کریں، کچھ بھی حذف نہیں ہوتا۔
- "صفائی" ٹیب سے حذف کی گئی فائلیں ری سائیکل بن میں نہیں جاتیں اور بحال نہیں کی جا سکتیں۔
- "صفائی" ٹیب آپ کی دستاویزات، تصاویر، موسیقی، ویڈیوز، ڈیسک ٹاپ یا ڈاؤن لوڈز کو کبھی نہیں چھوتا۔
- یہ کسی براؤزر یا ایپ کا کیشے صاف کرنے سے پہلے آپ سے اسے بند کرنے کو کہتا ہے۔
- اگر PC کی میموری کم ہو تو یہ ناپنے، اسکین کرنے یا صفائی سے پہلے آپ کو خبردار کرتا ہے۔
- یہ کبھی فولڈر لنکس کے ذریعے دوسرے فولڈرز میں نہیں جاتا۔
- Windows، WinSxS یا Installer فولڈرز میں فائلیں کبھی ہاتھ سے حذف نہ کریں۔


سرگزشت
------
جو کچھ صاف کیا گیا وہ صرف اسی PC پر یہاں محفوظ ہوتا ہے:
%LOCALAPPDATA%\DiskCleanupHelper\cleanup-history.log
اسے "تعارف" ٹیب سے کھولیں۔


اپ ڈیٹس
-------
شروع ہوتے وقت ایپ اپنے GitHub صفحے سے پوچھتی ہے کہ کیا کوئی نیا ورژن موجود ہے (دن میں زیادہ سے زیادہ ایک بار)۔
نیا ورژن پس منظر میں ڈاؤن لوڈ کیا جاتا ہے اور استعمال سے پہلے چیک کیا جاتا ہے (SHA256 اور ورژن نمبر)۔
پھر ایک پٹی "ابھی دوبارہ شروع کریں" کی پیشکش کرتی ہے۔ اگر آپ "بعد میں" چنیں تو اپ ڈیٹ ایپ بند کرنے پر انسٹال ہو جاتی ہے۔
خودکار چیک بند کرنے کے لیے "تعارف" ٹیب میں اس کا نشان ہٹا دیں۔ وہاں "اپ ڈیٹس چیک کریں" پھر بھی کام کرتا ہے۔
آپ کے PC کے بارے میں کچھ نہیں بھیجا جاتا۔


ان انسٹال کرنا
-------------
ترتیبات > ایپس > Disk Cleanup Helper > ان انسٹال کریں، یا "تعارف" ٹیب میں "ان انسٹال کریں" پر کلک کریں۔
اگر آپ نے اسے کبھی انسٹال نہیں کیا تو بس DiskCleanupHelper.exe حذف کر دیں۔


Windows کی کوئی ترتیب واپس کرنا
------------------------------
Command Prompt کو ایڈمنسٹریٹر کے طور پر کھولیں اور جس لائن کی ضرورت ہو وہ چلائیں:
    powercfg /h on                                          (ہائبرنیشن دوبارہ آن)
    DISM /Online /Set-ReservedStorageState /State:Enabled   (مخصوص اسٹوریج دوبارہ آن)
    compact.exe /compactos:never                            (Windows فائلوں کی کمپریشن بند)


ضروریات
-------
Windows 10 یا Windows 11۔ کچھ اور انسٹال کرنے کی ضرورت نہیں: یہ Windows میں شامل .NET Framework استعمال کرتا ہے۔

دستبرداری
---------
یہ پروگرام جیسا ہے ویسا ہی فراہم کیا جاتا ہے، کسی بھی قسم کی ضمانت کے بغیر۔ اسے اپنی ذمہ داری پر استعمال کریں۔
کسی بھی کمپیوٹر کی صفائی سے پہلے یقینی بنائیں کہ اہم فائلوں کا بیک اپ موجود ہے۔
