Disk Cleanup Helper
===================
برای خواندن این فایل از راست به چپ در دفترچه یادداشت (Notepad): کلید Ctrl را همراه با کلید Shift سمت راست فشار دهید.

دستیاری رایگان و متن‌باز برای Windows 10 و Windows 11.
نشان می‌دهد چه چیزی دیسک‌های شما را پر کرده و فضا را به‌طور ایمن آزاد می‌کند.
فقط یک فایل برنامه کوچک است. چیزی درباره رایانه شما نمی‌فرستد؛ فقط از GitHub می‌پرسد آیا نسخه جدیدی وجود دارد.


چه کاری انجام می‌دهد
--------------------
پاک‌سازی            پاک‌سازی ایمن حافظه‌های پنهان مرورگرها و برنامه‌ها، فایل‌های موقت، فایل‌های به‌روزرسانی قدیمی،
                    باقی‌مانده‌های Windows و موارد دیگر. هر مورد توضیح می‌دهد چه چیزی را نگه می‌دارید و چه چیزی را از دست می‌دهید.
تحلیل دیسک          بزرگ‌ترین پوشه‌ها (برای دیدن محتوا دوبار کلیک کنید) و بزرگ‌ترین فایل‌ها را
                    در هر درایو نشان می‌دهد تا بفهمید چه چیزی فضای شما را گرفته است.
سلامت دیسک          نشان می‌دهد هر دیسک و درایو سالم است یا نه و چقدر پر است، همراه با نمایش زنده دما
                    و نمودارهای سابقه، و اسکن خطای خود Windows را اجرا می‌کند.
جزئیات SMART        داده‌های کامل خودپایشی هر دیسک.
عملکرد دیسک         فعالیت زنده دیسک و یک آزمون سرعت.
جزئیات دستگاه       Windows، پردازنده، حافظه، گرافیک، صفحه‌نمایش‌ها، فضای ذخیره‌سازی، باتری، شبکه
                    و صدا، مانند «ابزار عیب‌یابی DirectX» در Windows. می‌توانید آن را کپی کنید یا به‌صورت فایل متنی ذخیره کنید.
نکته‌ها و پرسش‌ها   عادت‌های ساده‌ای که نمی‌گذارند دیسک شما پر شود، و پاسخ پرسش‌های رایج.
درباره              آن را با یک مورد در منوی شروع و یک میان‌بر روی میز کار روی رایانه نصب کنید، یا حذف نصب کنید.
                    به‌روزرسانی‌ها را بررسی کنید.


چگونه شروع کنیم
---------------
1. روی DiskCleanupHelper.exe دوبار کلیک کنید.
2. Windows می‌پرسد «آیا می‌خواهید به این برنامه اجازه دهید تغییراتی ایجاد کند؟». روی «بله» کلیک کنید.
   اگر روی «خیر» کلیک کنید، برنامه باز هم باز می‌شود، اما مواردی که به دسترسی سرپرست نیاز دارند خاکستری هستند.
3. اگر Windows پیام «Windows از رایانه شما محافظت کرد» را نشان داد، روی «اطلاعات بیشتر» و سپس «به هر حال اجرا شود» کلیک کنید.
   این پیام ممکن است برای برنامه‌های جدیدی که Microsoft هنوز آن‌ها را نمی‌شناسد نمایش داده شود.
4. زبان: روی دکمه زبان (نماد کره زمین) در بالای پنجره کلیک کنید و یک زبان انتخاب کنید. پنجره فوراً
   به آن زبان تغییر می‌کند و انتخاب شما را به خاطر می‌سپارد.
5. روشن یا تیره: روی دکمه «حالت تیره» / «حالت روشن» در بالای پنجره کلیک کنید. برنامه انتخاب شما را به خاطر می‌سپارد.
6. برای نگه داشتن آن: زبانه «درباره» را باز کنید و روی «نصب روی این رایانه» کلیک کنید.
   پس از آن در منوی شروع، روی میز کار و در تنظیمات > برنامه‌ها نمایش داده می‌شود.
   برای نصب به دسترسی سرپرست نیاز نیست.


چگونه استفاده کنیم
------------------
زبانه «پاک‌سازی»:
1. برنامه‌هایی را که لازم ندارید ببندید، به‌ویژه مرورگرها، برنامه‌های گفتگو، ویرایشگرهای کد و بازی‌ها.
2. حجم‌ها هنگام باز شدن برنامه خودبه‌خود اندازه‌گیری می‌شوند. یکی دو دقیقه طول می‌کشد. برای توقف روی «توقف» کلیک کنید،
   یا برای اندازه‌گیری دوباره روی «اندازه‌گیری حجم‌ها» کلیک کنید.
3. هر گروه حجم کل خود را نشان می‌دهد. روی عنوان یک گروه کلیک کنید تا جمع شود یا دوباره باز شود؛
   برنامه به خاطر می‌سپارد کدام گروه‌ها را جمع کرده‌اید.
4. روی هر مورد کلیک کنید تا بخوانید چیست، کجاست و چه چیزی را نگه می‌دارید یا از دست می‌دهید.
5. کادر هر موردی را که می‌خواهید پاک‌سازی شود علامت بزنید، یا روی «انتخاب همه موارد امن» کلیک کنید.
   عنوان هر گروه نشان می‌دهد چند مورد از آن انتخاب شده است.
6. روی «پاک‌سازی انتخاب‌شده‌ها» کلیک کنید. فهرست دقیق را نشان می‌دهد و پیش از حذف هر چیزی از شما می‌پرسد.

زبانه «تحلیل دیسک»:
1. یک درایو (یا «فقط پوشه کاربری من») را انتخاب کنید و روی «اسکن» کلیک کنید. اسکن کل درایو ممکن است چند دقیقه طول بکشد.
2. یک سمت: بزرگ‌ترین پوشه‌ها. برای دیدن محتوای یک پوشه روی آن دوبار کلیک کنید، و برای برگشتن روی «بالا» کلیک کنید.
3. سمت دیگر: بزرگ‌ترین فایل‌ها. فایل‌ها را انتخاب کنید و «انتقال به سطل بازیافت» یا «حذف دائمی» را انتخاب کنید.
   فایل‌های Windows و برنامه‌ها محافظت می‌شوند و اینجا قابل حذف نیستند.

زبانه «سلامت دیسک»:
- هر دیسک را نشان می‌دهد (با دما، میزان فرسودگی و تعداد خطاها، وقتی با دسترسی سرپرست اجرا شده باشد)
  و اینکه هر درایو چقدر پر است.
- تا وقتی این زبانه باز است، دما هر چند ثانیه یک بار خودبه‌خود به‌روز می‌شود.
- نشانگر ماوس را روی یک نمودار سابقه نگه دارید تا مقدار دقیق و زمان ذخیره شدن آن را ببینید.
- «بررسی برای یافتن خطا» بررسی فقط‌خواندنی خود Windows را روی درایو Windows اجرا می‌کند.
- «بهینه‌سازی درایوها» ابزار بهینه‌سازی درایو خود Windows را باز می‌کند.

زبانه «عملکرد دیسک»:
- نشان می‌دهد دیسک انتخاب‌شده همین حالا چقدر مشغول است، همراه با نمودارهای دو دقیقه اخیر.
  نشانگر ماوس را روی یک نمودار نگه دارید تا مقادیر دقیق را ببینید.
- «اجرای آزمون سرعت» اندازه می‌گیرد که دیسک واقعاً با چه سرعتی می‌نویسد و می‌خواند. نتیجه ذخیره می‌شود
  تا بعداً بتوانید مقایسه کنید.


معنای گروه‌های پاک‌سازی
-----------------------
امن              حافظه‌های پنهان و فایل‌های موقت. برنامه‌ها خودشان آن‌ها را دوباره می‌سازند.
                 پاک‌سازی حافظه پنهان مرورگرها و برنامه‌ها، گذرواژه‌ها، نشانک‌ها، سابقه مرور و اطلاعات ورود شما را حفظ می‌کند.
سرپرست           فایل‌های به‌روزرسانی قدیمی برنامه‌های نصب‌شده (3 مورد جدیدتر هر برنامه حفظ می‌شود)،
                 و پاک‌سازی اجزای Windows توسط خود Microsoft.
به انتخاب شما    چیز کوچکی را از دست می‌دهید: سابقه پروژه‌های قدیمی، آهنگ‌های دانلودشده،
                 پیش‌نمایش‌های ویدیو، فایل‌های تخلیه حافظه (Crash dump)، یا آنچه در سطل بازیافت است.
تنظیم            کلیدهای Windows که فضا آزاد می‌کنند: خواب زمستانی، فضای ذخیره‌سازی رزروشده، CompactOS،
                 و حسگر ذخیره‌سازی.
فقط اطلاعات      چیزهای بزرگی که ابزار فقط نشان می‌دهد و باز می‌کند و هرگز حذف نمی‌کند: نصب قبلی Windows،
                 بزرگ‌ترین برنامه‌ها، بازیابی سیستم، Docker، WSL، بارگیری‌ها.

فقط مواردی که روی رایانه شما وجود دارند فهرست می‌شوند.


ایمنی
-----
- تا وقتی چیزی را انتخاب و تأیید نکنید، حذف نمی‌شود.
- فایل‌هایی که زبانه «پاک‌سازی» حذف می‌کند به سطل بازیافت نمی‌روند و قابل بازیابی نیستند.
- زبانه «پاک‌سازی» هرگز به اسناد، عکس‌ها، موسیقی، ویدیوها، میز کار یا بارگیری‌های شما دست نمی‌زند.
- پیش از پاک کردن حافظه پنهان یک مرورگر یا برنامه، از شما می‌خواهد آن را ببندید.
- اگر حافظه رایانه کم باشد، پیش از اندازه‌گیری، اسکن یا پاک‌سازی به شما هشدار می‌دهد.
- هرگز پیوندهای پوشه را به پوشه‌های دیگر دنبال نمی‌کند.
- هرگز فایل‌های پوشه‌های Windows، WinSxS یا Installer را به‌صورت دستی حذف نکنید.


سابقه
-----
آنچه پاک‌سازی شده فقط روی همین رایانه ذخیره می‌شود، در:
%LOCALAPPDATA%\DiskCleanupHelper\cleanup-history.log
آن را از زبانه «درباره» باز کنید.


به‌روزرسانی‌ها
--------------
وقتی برنامه شروع به کار می‌کند، از صفحه GitHub خود می‌پرسد آیا نسخه جدیدی وجود دارد (حداکثر روزی یک بار).
نسخه جدید در پس‌زمینه دانلود می‌شود و پیش از استفاده بررسی می‌شود (مقدار SHA256 و شماره نسخه).
سپس نواری گزینه «اکنون راه‌اندازی مجدد شود» را پیشنهاد می‌کند. اگر «بعداً» را انتخاب کنید، به‌روزرسانی هنگام بستن برنامه نصب می‌شود.
برای خاموش کردن بررسی خودکار، علامت آن را در زبانه «درباره» بردارید. «بررسی به‌روزرسانی‌ها» در آنجا همچنان کار می‌کند.
هیچ چیزی درباره رایانه شما فرستاده نمی‌شود.


حذف نصب
-------
تنظیمات > برنامه‌ها > Disk Cleanup Helper > حذف نصب، یا در زبانه «درباره» روی «حذف نصب» کلیک کنید.
اگر هرگز آن را نصب نکرده‌اید، فقط DiskCleanupHelper.exe را حذف کنید.


برگرداندن یک تنظیم Windows
--------------------------
خط فرمان را به‌عنوان سرپرست باز کنید و خطی را که لازم دارید اجرا کنید:
    powercfg /h on                                          (روشن کردن دوباره خواب زمستانی)
    DISM /Online /Set-ReservedStorageState /State:Enabled   (روشن کردن دوباره فضای ذخیره‌سازی رزروشده)
    compact.exe /compactos:never                            (توقف فشرده‌سازی فایل‌های Windows)


پیش‌نیازها
----------
Windows 10 یا Windows 11. نیازی به نصب چیز دیگری نیست: از .NET Framework داخلی Windows استفاده می‌کند.
