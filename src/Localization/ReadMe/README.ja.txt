DISK CLEANUP HELPER
===================

Windows 10 と Windows 11 用の無料のオープン ソース ツールです。
ディスクを何が占めているかを表示し、安全に領域を解放します。
小さなプログラム ファイル 1 つだけで動作します。PC に関する情報は何も送信しません。新しいバージョンがあるかどうかを GitHub に確認するだけです。


できること
----------
クリーンアップ  ブラウザーやアプリのキャッシュ、一時ファイル、古い更新ファイル、Windows の残りファイル
                などを安全にクリーンアップします。各項目に、何が残り何が失われるかが説明されています。
ディスク分析    任意のドライブで最も大きいフォルダー (ダブルクリックで中を表示) と最も大きいファイルを
                表示するので、何が領域を使っているかを見つけられます。
ディスクの状態  各ディスクとドライブが正常かどうか、どのくらいいっぱいかを、リアルタイムの温度と
                履歴グラフとともに表示し、Windows 自体のエラー スキャンを開始します。
SMART の詳細    各ディスクの自己監視データのすべて。
ディスクのパフォーマンス  リアルタイムのディスク アクティビティと速度テスト。
デバイスの詳細    Windows、プロセッサ、メモリ、グラフィックス、ディスプレイ、ストレージ、バッテリー、ネットワーク、
                  サウンドを、Windows の DirectX 診断ツールのように表示します。コピーしたり、テキスト ファイルとして保存したりできます。
ヒントと FAQ    ディスクがいっぱいにならないための簡単な習慣と、よくある質問への答え。
バージョン情報  スタート メニューの項目とデスクトップのショートカット付きで PC にインストール、またはアンインストールします。
                更新を確認します。


起動方法
--------
1. DiskCleanupHelper.exe をダブルクリックします。
2. Windows に「このアプリがデバイスに変更を加えることを許可しますか?」と表示されます。「はい」をクリックします。
   「いいえ」をクリックしても起動しますが、管理者権限が必要な項目は灰色で表示されます。
3. Windows に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」をクリックしてから「実行」をクリックします。
   これは、まだ Microsoft に認識されていない新しいプログラムで表示されることがあります。
4. 言語: 右上の言語ボタン (地球儀) をクリックして言語を選びます。ウィンドウはすぐにその言語に
   切り替わり、選択を記憶します。
5. ライトまたはダーク: 右上の「ダーク モード」/「ライト モード」ボタンをクリックします。アプリは選択を記憶します。
6. 残しておくには: 「バージョン情報」タブを開いて「この PC にインストール」をクリックします。
   スタート メニュー、デスクトップ、設定 > アプリ に表示されるようになります。
   インストールに管理者権限は不要です。


使い方
------
「クリーンアップ」タブ:
1. 不要なプログラム、特にブラウザー、チャット アプリ、コード エディター、ゲームを閉じます。
2. アプリを開くと、サイズが自動的に測定されます。1 ～ 2 分かかります。「停止」をクリックすると停止し、
   「サイズを測定」をクリックするともう一度測定します。
3. 各グループには合計サイズが表示されます。グループのタイトルをクリックすると、折りたたんだり、もう一度開いたりできます。
   どのグループを折りたたんだかは、アプリが記憶します。
4. 項目をクリックすると、内容、場所、残るものと失われるものが表示されます。
5. クリーンアップしたい各項目のボックスにチェックを入れるか、「安全な項目をすべて選択」をクリックします。
   各グループのタイトルには、そのグループで選択されている項目の数が表示されます。
6. 「選択項目をクリーンアップ」をクリックします。正確な一覧が表示され、何かを削除する前に確認を求められます。

「ディスク分析」タブ:
1. ドライブ (または「自分のユーザー フォルダーのみ」) を選んで「スキャン」をクリックします。ドライブ全体の場合は数分かかることがあります。
2. 左側: 最も大きいフォルダー。フォルダーをダブルクリックすると中が表示され、「上へ」をクリックすると戻ります。
3. 右側: 最も大きいファイル。ファイルを選んで「ごみ箱に移動」または「完全に削除」を選びます。
   Windows とプログラムのファイルは保護されているため、ここでは削除できません。

「ディスクの状態」タブ:
- 各ディスク (管理者権限で起動した場合は温度、消耗度、エラー数も) と、
  各ドライブがどのくらいいっぱいかを表示します。
- タブを開いている間、温度は数秒ごとに自動的に更新されます。
- 履歴グラフにポインターを合わせると、正確な値と、それが保存された日時が表示されます。
- 「エラーをスキャン」は、Windows ドライブに対して Windows 自体の読み取り専用チェックを実行します。
- 「ドライブの最適化」は、Windows 自体のドライブ最適化ツールを開きます。

「ディスクのパフォーマンス」タブ:
- 選択したディスクの現在の負荷を、直近 2 分間のグラフとともに表示します。
  グラフにポインターを合わせると、正確な値が表示されます。
- 「速度テストを実行」は、ディスクが実際にどのくらいの速さで書き込みと読み取りができるかを測定します。結果は保存されるので、
  後で比較できます。


クリーンアップ グループの意味
-----------------------------
安全          キャッシュと一時ファイルです。プログラムが自動的に再作成します。
              ブラウザーとアプリのキャッシュを削除しても、パスワード、ブックマーク、履歴、ログイン情報は残ります。
管理者        インストール済みプログラムの古い更新ファイル (プログラムごとに最新 3 個を保持) と、
              Microsoft 自身による Windows コンポーネントのクリーンアップ。
ご自身で判断  小さなものが失われます: 古いプロジェクトの履歴、ダウンロードした曲、
              ビデオのプレビュー、クラッシュ ダンプ ファイル、またはごみ箱の中身。
設定          領域を解放する Windows の設定: 休止状態、予約済み記憶域、CompactOS、
              ストレージ センサー。
情報のみ      ツールが表示して開くだけで、削除はしない大きなもの: 以前の Windows の
              インストール、最も大きいプログラム、システムの復元、Docker、WSL、ダウンロード。

お使いの PC に存在する項目だけが表示されます。


安全性
------
- 選択して確認するまで、何も削除されません。
- 「クリーンアップ」タブで削除したファイルはごみ箱に移動せず、復元できません。
- 「クリーンアップ」タブが、ドキュメント、写真、音楽、ビデオ、デスクトップ、ダウンロードに触れることはありません。
- ブラウザーやアプリのキャッシュをクリーンアップする前に、そのブラウザーやアプリを閉じるよう求めます。
- 測定、スキャン、クリーンアップの前に PC のメモリが不足している場合は警告します。
- フォルダーのリンクをたどって他のフォルダーに入ることはありません。
- Windows、WinSxS、Installer フォルダー内のファイルは絶対に手動で削除しないでください。


履歴
----
クリーンアップした内容は、この PC の次の場所にのみ保存されます:
%LOCALAPPDATA%\DiskCleanupHelper\cleanup-history.log
「バージョン情報」タブから開けます。


更新
----
起動時に、アプリは自身の GitHub ページで新しいバージョンがあるかどうかを確認します (多くても 1 日 1 回)。
新しいバージョンはバックグラウンドでダウンロードされ、使われる前に確認されます (SHA256 とバージョン番号)。
その後、バーに「今すぐ再起動」が表示されます。「後で」を選ぶと、アプリを閉じたときに更新がインストールされます。
自動確認をオフにするには、「バージョン情報」タブでチェックを外します。そこにある「更新を確認」は引き続き使えます。
PC に関する情報は何も送信されません。


アンインストール
----------------
設定 > アプリ > Disk Cleanup Helper > アンインストール、または「バージョン情報」タブで「アンインストール」をクリックします。
インストールしていない場合は、DiskCleanupHelper.exe を削除するだけです。


Windows の設定を元に戻す
--------------------------
コマンド プロンプトを管理者として開き、必要な行を実行します:
    powercfg /h on                                          (休止状態をオンに戻す)
    DISM /Online /Set-ReservedStorageState /State:Enabled   (予約済み記憶域をオンに戻す)
    compact.exe /compactos:never                            (Windows ファイルの圧縮を停止する)


動作環境
--------
Windows 10 または Windows 11。他にインストールするものはありません: Windows に組み込まれている .NET Framework を使います。
