DISK CLEANUP HELPER
===================

一款适用于 Windows 10 和 Windows 11 的免费开源助手。
它会显示是什么占满了你的磁盘，并安全地释放空间。
它只是一个小小的程序文件。它不会发送任何有关你电脑的信息；它只会询问 GitHub 是否有新版本。


功能介绍
--------
清理            安全清理浏览器和应用缓存、临时文件、旧的更新文件、
                Windows 残留文件等。每个项目都会说明你会保留什么、失去什么。
分析磁盘        显示任意驱动器上最大的文件夹（双击可查看其中的内容）和最大的文件，
                帮你找出是什么占用了空间。
磁盘健康        显示每个磁盘和驱动器是否健康、有多满，以及实时温度和历史图表，
                并可启动 Windows 自带的错误扫描。
SMART 详细信息  每个磁盘完整的自我监测数据。
磁盘性能        实时磁盘活动和速度测试。
设备详细信息    Windows、处理器、内存、显卡、屏幕、存储、电池、网络
                和声音，类似 Windows 的 DirectX 诊断工具。可以复制，或另存为文本文件。
提示和常见问题  让磁盘不被填满的简单习惯，以及常见问题的解答。
关于            把它安装到电脑上，并添加“开始”菜单项和桌面快捷方式，或者卸载它。
                检查更新。


如何启动
--------
1. 双击 DiskCleanupHelper.exe。
2. Windows 会询问“你要允许此应用对你的设备进行更改吗？”。单击“是”。
   如果单击“否”，它仍会打开，但需要管理员权限的项目会显示为灰色。
3. 如果 Windows 显示“Windows 已保护你的电脑”，请单击“更多信息”，然后单击“仍要运行”。
   对于 Microsoft 还不认识的新程序，可能会出现此提示。
4. 语言：单击右上角的语言按钮（地球图标），然后选择一种语言。窗口会立即切换为该语言，
   并记住你的选择。
5. 浅色或深色：单击右上角的“深色模式”/“浅色模式”按钮。应用会记住你的选择。
6. 要保留它：打开“关于”选项卡，然后单击“安装到这台电脑”。
   之后它会出现在“开始”菜单、桌面和“设置 > 应用”中。
   安装无需管理员权限。


使用方法
--------
“清理”选项卡：
1. 关闭不需要的程序，特别是浏览器、聊天应用、代码编辑器和游戏。
2. 应用打开时会自行计算大小。这需要一两分钟。单击“停止”可停止，
   单击“计算大小”可重新计算。
3. 每个分组都会显示其总大小。单击分组的标题可将其折叠或重新展开；
   应用会记住你折叠了哪些分组。
4. 单击任一项目，查看它是什么、在哪里，以及你会保留或失去什么。
5. 勾选每个要清理的项目的复选框，或单击“全选安全项”。
   每个分组的标题会显示其中已选中的项目数。
6. 单击“清理所选项”。它会显示确切的列表，并在删除任何内容之前征求你的确认。

“分析磁盘”选项卡：
1. 选择一个驱动器（或“仅我的用户文件夹”），然后单击“扫描”。扫描整个驱动器可能需要几分钟。
2. 左侧：最大的文件夹。双击文件夹可查看其中的内容，单击“向上”可返回。
3. 右侧：最大的文件。选择文件，然后选择“移到回收站”或“永久删除”。
   Windows 和程序文件受到保护，无法在这里删除。

“磁盘健康”选项卡：
- 显示每个磁盘（以管理员权限启动时，还会显示温度、磨损和错误计数）
  以及每个驱动器有多满。
- 打开此选项卡时，温度每隔几秒会自行更新。
- 将指针指向历史图表，可查看确切的数值及其保存时间。
- “扫描错误”会对 Windows 驱动器运行 Windows 自带的只读检查。
- “优化驱动器”会打开 Windows 自带的驱动器优化工具。

“磁盘性能”选项卡：
- 显示所选磁盘当前的繁忙程度，并附有最近 2 分钟的图表。
  将指针指向图表，可查看确切的数值。
- “运行速度测试”会测量磁盘实际能达到的写入和读取速度。结果会被保存，
  方便你以后比较。


清理分组的含义
--------------
安全          缓存和临时文件。程序会自行重建它们。
              清理浏览器和应用缓存时，会保留你的密码、书签、历史记录和登录状态。
管理员        已安装程序的旧更新文件（每个程序保留最新的 3 个），
              以及 Microsoft 自己的 Windows 组件清理。
由你决定      你会失去一些小东西：旧项目历史记录、已下载的歌曲、
              视频预览、崩溃转储文件，或回收站中的内容。
设置          可以释放空间的 Windows 开关：休眠、保留的存储、CompactOS
              和存储感知。
仅供参考      本工具只显示并打开、从不删除的大型项目：以前的 Windows 安装、
              最大的程序、系统还原、Docker、WSL、“下载”文件夹。

只列出你的电脑上存在的项目。


安全保障
--------
- 在你选择并确认之前，不会删除任何内容。
- 通过“清理”选项卡删除的文件不会进入回收站，并且无法恢复。
- “清理”选项卡从不触碰你的文档、照片、音乐、视频、桌面或下载内容。
- 在清理浏览器或应用的缓存之前，它会请你先关闭该浏览器或应用。
- 在计算大小、扫描或清理之前，如果电脑内存不足，它会提醒你。
- 它从不跟随文件夹链接进入其他文件夹。
- 切勿手动删除 Windows、WinSxS 或 Installer 文件夹中的文件。


历史记录
--------
清理过的内容仅保存在这台电脑上，位置为：
%LOCALAPPDATA%\DiskCleanupHelper\cleanup-history.log
可以从“关于”选项卡中打开它。


更新
----
应用启动时，会询问其 GitHub 页面是否有新版本（每天最多一次）。
新版本会在后台下载，并在使用之前经过检查（SHA256 和版本号）。
随后会出现一个提示栏，提供“立即重新启动”。如果你选择“稍后”，更新会在你关闭应用时安装。
要关闭自动检查，请在“关于”选项卡中取消勾选。那里的“检查更新”仍然可用。
不会发送任何有关你电脑的信息。


卸载
----
“设置 > 应用 > Disk Cleanup Helper > 卸载”，或单击“关于”选项卡中的“卸载”。
如果你从未安装过它，直接删除 DiskCleanupHelper.exe 即可。


撤销 Windows 设置
-----------------
以管理员身份打开命令提示符，然后运行你需要的那一行：
    powercfg /h on                                          （重新打开休眠）
    DISM /Online /Set-ReservedStorageState /State:Enabled   （重新打开保留的存储）
    compact.exe /compactos:never                            （停止压缩 Windows 文件）


系统要求
--------
Windows 10 或 Windows 11。无需安装其他任何东西：它使用 Windows 内置的 .NET Framework。
