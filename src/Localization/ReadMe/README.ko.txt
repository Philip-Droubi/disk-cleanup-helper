DISK CLEANUP HELPER
===================

Windows 10 및 Windows 11용 무료 오픈 소스 도우미입니다.
디스크를 무엇이 채우고 있는지 보여 주고 공간을 안전하게 확보합니다.
작은 프로그램 파일 하나로 되어 있습니다. PC에 관한 정보는 아무것도 보내지 않으며, 새 버전이 있는지 GitHub에 묻기만 합니다.


기능
----
정리              브라우저 및 앱 캐시, 임시 파일, 오래된 업데이트 파일, Windows 잔여 파일 등을
                  안전하게 정리합니다. 각 항목마다 무엇이 유지되고 무엇을 잃는지 설명합니다.
디스크 분석       모든 드라이브에서 가장 큰 폴더(두 번 클릭하면 안을 볼 수 있음)와 가장 큰 파일을
                  보여 주므로 무엇이 공간을 차지하는지 찾을 수 있습니다.
디스크 상태       각 디스크와 드라이브가 정상인지, 얼마나 찼는지 실시간 온도 및 기록 차트와 함께
                  보여 주고, Windows 자체 오류 검사를 시작합니다.
SMART 세부 정보   각 디스크의 전체 자체 모니터링 데이터입니다.
디스크 성능       실시간 디스크 활동과 속도 테스트입니다.
장치 세부 정보    Windows, 프로세서, 메모리, 그래픽, 화면, 저장소, 배터리, 네트워크, 사운드를
                  Windows의 DirectX 진단 도구처럼 보여 줍니다. 복사하거나 텍스트 파일로 저장할 수 있습니다.
팁 및 FAQ         디스크가 가득 차지 않게 하는 간단한 습관과 자주 묻는 질문에 대한 답변입니다.
정보              시작 메뉴 항목과 바탕 화면 바로 가기와 함께 PC에 설치하거나, 제거합니다.
                  업데이트를 확인합니다.


시작하는 방법
-------------
1. DiskCleanupHelper.exe를 두 번 클릭하세요.
2. Windows에서 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"라고 묻습니다. 예를 클릭하세요.
   아니요를 클릭해도 앱은 열리지만, 관리자 권한이 필요한 항목은 회색으로 표시됩니다.
3. Windows에 "Windows의 PC 보호"가 표시되면 "추가 정보"를 클릭한 다음 "실행"을 클릭하세요.
   아직 Microsoft에 알려지지 않은 새 프로그램에서 이 메시지가 나타날 수 있습니다.
4. 언어: 오른쪽 위의 언어 단추(지구본)를 클릭하고 언어를 선택하세요. 창이 바로 그 언어로
   바뀌며 선택한 언어를 기억합니다.
5. 밝게 또는 어둡게: 오른쪽 위의 "다크 모드" / "라이트 모드" 단추를 클릭하세요. 앱이 선택을 기억합니다.
6. 계속 사용하려면: 정보 탭을 열고 "이 PC에 설치"를 클릭하세요.
   그러면 시작 메뉴, 바탕 화면, 설정 > 앱에 표시됩니다.
   설치에는 관리자 권한이 필요하지 않습니다.


사용 방법
---------
정리 탭:
1. 필요 없는 프로그램, 특히 브라우저, 채팅 앱, 코드 편집기, 게임을 닫으세요.
2. 앱을 열면 크기가 자동으로 측정됩니다. 1~2분 정도 걸립니다. 멈추려면 "중지"를 클릭하고,
   다시 측정하려면 "크기 측정"을 클릭하세요.
3. 각 그룹에 총 크기가 표시됩니다. 그룹 제목을 클릭하면 그룹을 접거나 다시 펼칠 수 있습니다.
   앱은 어떤 그룹을 접었는지 기억합니다.
4. 항목을 클릭하면 무엇인지, 어디에 있는지, 무엇을 유지하고 무엇을 잃는지 읽을 수 있습니다.
5. 정리할 각 항목의 확인란을 선택하거나 "안전 항목 모두 선택"을 클릭하세요.
   각 그룹 제목에 그 그룹에서 선택된 항목 수가 표시됩니다.
6. "선택 항목 정리"를 클릭하세요. 정확한 목록을 보여 주고, 삭제하기 전에 확인을 요청합니다.

디스크 분석 탭:
1. 드라이브(또는 "내 사용자 폴더만")를 선택하고 "검사"를 클릭하세요. 드라이브 전체는 몇 분 정도 걸릴 수 있습니다.
2. 왼쪽: 가장 큰 폴더. 폴더를 두 번 클릭하면 안을 볼 수 있고, "위로"를 클릭하면 돌아갑니다.
3. 오른쪽: 가장 큰 파일. 파일을 선택하고 "휴지통으로 이동" 또는 "영구 삭제"를 선택하세요.
   Windows 파일과 프로그램 파일은 보호되므로 여기에서 삭제할 수 없습니다.

디스크 상태 탭:
- 각 디스크(관리자 권한으로 시작한 경우 온도, 마모, 오류 횟수 포함)와
  각 드라이브가 얼마나 찼는지 보여 줍니다.
- 탭이 열려 있는 동안 온도가 몇 초마다 자동으로 업데이트됩니다.
- 기록 차트를 가리키면 정확한 값과 언제 저장되었는지 볼 수 있습니다.
- "오류 검사"는 Windows 드라이브에 대해 Windows 자체 읽기 전용 검사를 실행합니다.
- "드라이브 최적화"는 Windows 자체 드라이브 최적화 도구를 엽니다.

디스크 성능 탭:
- 선택한 디스크가 지금 얼마나 바쁜지 최근 2분 동안의 차트와 함께 보여 줍니다.
  차트를 가리키면 정확한 값을 볼 수 있습니다.
- "속도 테스트 실행"은 디스크가 실제로 얼마나 빠르게 쓰고 읽을 수 있는지 측정합니다. 결과가 저장되므로
  나중에 비교할 수 있습니다.


정리 그룹의 의미
----------------
안전          캐시와 임시 파일입니다. 프로그램이 스스로 다시 만듭니다.
              브라우저 및 앱 캐시를 정리해도 암호, 북마크, 기록, 로그인은 유지됩니다.
관리자        설치된 프로그램의 오래된 업데이트 파일(프로그램마다 최신 3개 유지)과
              Microsoft 자체 Windows 구성 요소 정리입니다.
직접 판단     작은 것을 잃게 됩니다: 오래된 프로젝트 기록, 다운로드한 노래,
              동영상 미리 보기, 크래시 덤프 파일, 또는 휴지통에 있는 항목.
설정          공간을 확보하는 Windows 스위치: 최대 절전 모드, 예약된 저장소, CompactOS,
              저장소 센스.
정보만        도구가 표시하고 열기만 하며 절대 삭제하지 않는 큰 항목: 이전 Windows
              설치, 가장 큰 프로그램, 시스템 복원, Docker, WSL, 다운로드.

PC에 있는 항목만 표시됩니다.


안전
----
- 선택하고 확인하기 전에는 아무것도 삭제되지 않습니다.
- 정리 탭에서 삭제한 파일은 휴지통으로 가지 않으며 복원할 수 없습니다.
- 정리 탭은 문서, 사진, 음악, 동영상, 바탕 화면, 다운로드를 절대 건드리지 않습니다.
- 캐시를 정리하기 전에 브라우저나 앱을 닫으라고 요청합니다.
- 측정, 검사 또는 정리 전에 PC 메모리가 부족하면 경고합니다.
- 폴더 링크를 따라 다른 폴더로 들어가지 않습니다.
- Windows, WinSxS, Installer 폴더의 파일은 절대 직접 삭제하지 마세요.


기록
----
정리한 내용은 이 PC에만 다음 위치에 저장됩니다:
%LOCALAPPDATA%\DiskCleanupHelper\cleanup-history.log
정보 탭에서 열 수 있습니다.


업데이트
--------
앱이 시작되면 앱의 GitHub 페이지에 새 버전이 있는지 묻습니다(하루 최대 한 번).
새 버전은 백그라운드에서 다운로드되며, 사용하기 전에 확인됩니다(SHA256 및 버전 번호).
그런 다음 표시줄에 "지금 다시 시작"이 나타납니다. "나중에"를 선택하면 앱을 닫을 때 업데이트가 설치됩니다.
자동 확인을 끄려면 정보 탭에서 확인란의 선택을 해제하세요. 그곳의 "업데이트 확인"은 계속 작동합니다.
PC에 관한 정보는 아무것도 전송되지 않습니다.


제거
----
설정 > 앱 > Disk Cleanup Helper > 제거를 사용하거나, 정보 탭에서 "제거"를 클릭하세요.
설치한 적이 없다면 DiskCleanupHelper.exe만 삭제하면 됩니다.


Windows 설정 되돌리기
---------------------
명령 프롬프트를 관리자 권한으로 열고 필요한 줄을 실행하세요:
    powercfg /h on                                          (최대 절전 모드 다시 켜기)
    DISM /Online /Set-ReservedStorageState /State:Enabled   (예약된 저장소 다시 켜기)
    compact.exe /compactos:never                            (Windows 파일 압축 중지)


요구 사항
---------
Windows 10 또는 Windows 11. 따로 설치할 것은 없습니다. Windows에 기본 제공되는 .NET Framework를 사용합니다.
